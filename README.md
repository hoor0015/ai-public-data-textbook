# AI 기반 공공데이터 분석 교재

VSCode + Claude Code 조합으로 AI 에이전트를 활용해 한국 공공데이터를 분석하는 학부 교재. 15주 학기 기준 8주차 중간고사·15주차 기말고사를 제외한 13개 콘텐츠 주차(1-7·9-14주) × 주당 2회차(1회차 이론, 2회차 실습) = 총 26개 장. 형식은 통계학입문책(QSS 한국 공공데이터판)을 계승한다. 독자는 문과(행정학과) 학부 1학년이며, 학생의 역할은 코딩이 아니라 에이전트에 대한 지시·검증·해석이다.

2026-09-04 개편: 5주차를 「남이 만든 스킬 가져다 쓰기」(1회차)와 「GitHub의 스킬 설치해 공문서 다루기」(2회차)로 교체했다. 학생은 kordoc 플러그인(chrisryugj/kordoc, MIT)을 대화창에서 설치해 공문서(hwp·hwpx·pdf)를 Markdown으로 바꾸고 그 안의 표를 데이터로 옮긴다. 난이도를 낮추라는 요구에 따라 스킬 인자 문법(`$ARGUMENTS`, `argument-hint`, `arguments:`)과 `context: fork`를 교재 전체에서 없앴고, 모든 스킬은 대화에서 대상과 조건을 말해 주면 알아듣고 빠진 것은 되묻는 방식으로 통일했다. 같은 날 학생이 일부러 오류를 만들어 보는 실습(값·열 삭제, 스크립트 깨뜨리기, 틀린 주소 등록, 왜곡 그래프 제작)도 모두 걷어 냈다. 에이전트가 스스로 틀리는 장면은 그대로 둔다.

2026-09-03 개편: 옛 2·3주차(작동 원리, 지시 설계)를 2주차 한 주로 통합하고, Skill을 4주차(기초, 직접 만들기)와 5주차(공개된 스킬 설치해 쓰기)의 두 주로 늘렸다. 옛 4주차(환경)는 3주차가 되었고 6주차 이후는 그대로다. 같은 날 모든 실습 장을 이론 장보다 길게 확장했다: 단계 추가, 예상 결과와 검증의 구체화, 에이전트가 틀리는 장면, 선택 심화 단계, 자주 겪는 문제·과제 확장. 이어서 관찰 일지와, 에이전트의 답을 메모 파일이나 기록표·대조표·양식에 옮겨 적고 견주는 성격의 단계·과제를 실습 장 전체에서 걷어 냈다(실습 장은 실제 문자 수 2.8만-5.5만 자). 실습 장의 모든 수치는 `code/chNN_practice*.py`로 `data/`에서 다시 계산한 값이다.

## 집필 원칙 (요약)

- 모든 본문 수치는 실제 데이터에서 계산해 검증한 값만 사용. 모든 그림은 `code/`의 스크립트로 재현 가능.
- Claude Code 기능(계획 모드, CLAUDE.md, Skill, 플러그인·마켓플레이스, 서브에이전트, MCP)과 포털·법령 사실관계는 공식 문서(code.claude.com/docs, law.go.kr 등)로 확인 후 서술. 공식 문서로 확인되지 않은 문법(예: allowed-tools의 MCP 도구 표기)은 쓰지 않는다.
- 6·12주차 MCP 실습은 kosis MCP 서버(HTTP, `claude mcp add --transport http kosis https://kosismcp2026.vercel.app/api/mcp`로 등록. 학생은 에이전트에게 등록을 지시한다)를 사용하며, 본문의 수집 흐름과 수치는 실제 MCP 호출로 검증한 값이다.
- 매 실습 장에 "에이전트가 틀리는 장면"(틀림 → 검증에서 발견 → 재지시 → 수정)과 세 겹 검증 절차 포함 (예: 결측 fillna(0)으로 군위군이 전국 최저 출산율로 둔갑, 병합 시 미추홀구가 짝을 못 찾음, 보고서 초안의 "약 90%"가 결과 파일에 없는 수치).
